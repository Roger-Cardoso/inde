# INDE 0.2.0

INDE para criação, planejamento e publicação. Esta edição incorpora o Especial INT-01 (schema 37), com editor unificado, planejamento contextual e visual, espaço Comic e geração local de Sites e Edições.

## Compilar e abrir no Linux

Com as [dependências instaladas](GUIA.md#transportar-a-demo-e-preparar-a-ponte), execute na raiz:

```sh
sh Preparar-INDE-especial.sh
sh Abrir-INDE-especial.sh
```

A edição é distribuída em código-fonte. As fontes verificadas estão em `fontes/`; a construção aplica as integrações nativas de `cpp/`. Consulte o [guia](GUIA.md), o [roteiro GTK](ROTEIRO-GTK.md) e o [registro da integração](INTEGRACAO-01.md).
